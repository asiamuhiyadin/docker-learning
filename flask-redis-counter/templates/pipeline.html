01

Nginx as Gateway

All external traffic hits Nginx on port 5002. Nginx terminates the connection, applies upstream round-robin across Flask instances, and forwards the request over Docker's internal bridge network — keeping Flask containers fully isolated.

02

Horizontal Flask Scaling

docker compose up --scale flask=3 spawns multiple identical Flask containers. Because state lives in Redis (not in the container), any replica can serve any request — the defining property of a stateless service.

03

Redis Persistence

Visit counters survive container restarts because Redis is backed by a named Docker volume (redis-data). The volume mounts to /data inside the Redis container and uses RDB snapshotting.

04

Health & Observability

GET /health returns a JSON payload with Redis status, container ID, and uptime — ready for a load balancer health-check probe or an uptime monitor. GET /api/stats exposes raw metrics for external tooling.

nginx.conf — upstream definition NGINX 
upstream flask_cluster {
    server flask:5000;
}

server {
    listen 5002;
    location / {
        proxy_pass         http://flask_cluster;
        proxy_set_header   Host              $host;
        proxy_set_header   X-Real-IP         $remote_addr;
    }
}
